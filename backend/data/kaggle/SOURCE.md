# Kaggle Data Source

- Dataset: Supply Chain Analysis
- Kaggle reference: `harshsingh2209/supply-chain-analysis`
- URL: https://www.kaggle.com/datasets/harshsingh2209/supply-chain-analysis
- License: CC0: Public Domain
- File: `supply_chain_data.csv`

The source contains supply-chain product, supplier, pricing, order quantity, lead-time,
shipping, inspection, defect-rate, route, and cost fields. It does not contain SAP
purchase orders or supplier invoices.

ProcureOps maps those source fields into SAP-style purchase-order and invoice records.
Dates and controlled invoice exceptions are derived deterministically for the portfolio
workflow. The project does not claim that the derived records came from a real SAP
system.
